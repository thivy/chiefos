# Memory

`memory.md` holds brief, factual, durable context that improves future triage: communication preferences, priority relationships, customer domains and aliases, recurring projects or escalation paths, and standing meeting preferences.

Exclude guesses, one-off or completed tasks, transient notes and deadlines. Update existing entries rather than duplicating, replace anything newer user input contradicts, and keep user-authored content. Use short one-idea bullets and omit unknown values. Fill placeholder domains only from reliable evidence.

Template:

```markdown
# Personal Memory

## Communication Preferences

- Stable preference.

## Priority Relationships

- Name or role: durable priority context.

## Customer Domains

- `@example.com`: customer or account context.

## Recurring Context

- Durable project, meeting, or escalation context.
```
